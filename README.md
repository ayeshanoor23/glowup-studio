# GlowUp Studio 🌷

A responsive self-care and beauty routine planner built with vanilla HTML, CSS, and JavaScript.

## Features
- Add, complete, filter, and delete daily routine steps
- Track daily completion progress
- Save a personal beauty product shelf
- Write and save a note to yourself
- Dark mode
- Responsive layout for desktop and mobile
- Persists data in browser `localStorage`

## Run locally
No build tools or dependencies required.

1. Download or clone this repository.
2. Open `index.html` in a browser.

For a local development server, you can use the VS Code **Live Server** extension.

## Deploy with GitHub Pages
1. Push the project to a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.

## Project structure
```text
glowup-studio/
├── index.html
└── README.md
```

## Privacy
Routine steps, products, theme preference, and personal note are stored locally in your browser using `localStorage`. They are not sent to a server. Clearing browser storage will remove this saved data.
